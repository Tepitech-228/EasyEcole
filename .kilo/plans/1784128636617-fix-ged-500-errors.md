# Fix GED 500 Errors

## Status: COMPLETED

## Root Cause (confirmed)
Database tables were not fully synced with the new model definitions:
- `ged_document_types` columns were in `snake_case` (`short_code`, `default_confidentiality`, `dua_duration_years`, `is_permanent`) but Sequelize expects `camelCase`
- `ged_folders` was missing `domainId` column
- This caused `Unknown column 'documentType.shortCode' in 'field list'` and missing column errors

## Changes Applied

### 1. Database Schema Fixes
- Renamed `ged_document_types` columns to camelCase via migration script
- Added `domainId` to `ged_folders`
- Re-ran `sync-database.ts` successfully

### 2. Controller Fixes
- `FolderController.list`: Added `domainId` filter support
- `DocumentGedController.getAll`: Made `domain`/`documentType` includes conditional on query params
- `SessionGedController.get`: Made documents inclusion opt-in via `?includeDocuments=true`

## Verification
All queries now pass:
- Folder with domainId filter: OK
- DocumentGed with domain + documentType includes: OK
- SessionGed without documents: OK
- SessionGed with documents: OK

## Remaining Warnings (non-blocking)
- `ER_TOO_MANY_KEYS` on `aut_utilisateurs` during sync (ignored)
- `ER_FK_INCORRECT_OPTION` on `ged_document_types.domainId` FK (ignored)
