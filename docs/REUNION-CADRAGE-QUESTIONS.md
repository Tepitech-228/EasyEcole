## 4. Gestion des notes & Unités d'Enseignement (UE) — pédagogie

> Sujet structurant : le paramétrage des UE, des notes et des règles de validation détermine tout le calcul des moyennes, des bulletins et des délibérations. À valider avec le **responsable pédagogique**.

| # | Question | Priorité | Réponse / Décision |
|---|---|---|---|
| 4.1 | Le système **LMD (Licence-Master-Doctorat) avec ECTS** est-il en vigueur ? Combien d'**ECTS** par UE, par semestre, par année ? | ❗ Essentiel | |
| 4.2 | Comment les **UE** sont-elles structurées ? (UE par semestre, une UE regroupe-t-elle plusieurs cours/matières ?) Qui fournit la liste des UE et cours de chaque niveau ? | ❗ Essentiel | |
| 4.3 | Qui **paramètre** les UE, les cours et leurs **coefficients** (direction, responsable pédagogique, enseignant) ? | ❗ Essentiel | |
| 4.4 | Comment se calculent les **moyennes** : par UE (pondération des notes), par semestre, moyenne générale ? Quelles **pondérations** exactes ? | ❗ Essentiel | |
| 4.5 | Quelles **échelles de notation** : /20, /10, lettres (A–F), crédits ? Existe-t-il des **notes éliminatoires** (ex. < 10/20) ? | ❗ Essentiel | |
| 4.6 | **MCC (Modalités de Contrôle des Connaissances)** : quels types de contrôles (CC, examen final, TP, projet, oral) et leurs **pondérations** (ex. 40 % CC + 60 % examen) ? | ❗ Essentiel | |
| 4.7 | Quelles sont les **règles de validation d'une UE** : moyenne ≥ 10/20 ? ECTS acquis à partir de quelle note ? **Compensation** possible entre UE ? | ❗ Essentiel | |
| 4.8 | **Semestres** : combien par année ? Comment suivre les UE **en cours / validées / échouées** et les ECTS acquis ? | Important | |
| 4.9 | **Rattrapages (session 2)** : quand sont-ils organisés ? Qui les gère ? Quelle note est retenue après rattrapage ? | ❗ Essentiel | |
| 4.10 | **Délibérations du jury** : à quels moments ? Qui y participe ? Quelles décisions (admis, ajourné, avec mention, rattrapage) ? | ❗ Essentiel | |
| 4.11 | **Bulletins et relevés de notes** : format attendu (moyennes, mentions, crédits, classement) ? Qui les génère et les **valide** ? | ❗ Essentiel | |
| 4.12 | Les **absences** influent-elles sur les notes (seuil d'assiduité, note de présence) ? | Important | |
| 4.13 | Faut-il gérer les **équivalences, dispenses** et **dettes académiques** ? | Optionnel | |
| 4.14 | Qui **saisit les notes** (enseignants directement, service de scolarité) ? Qui les **valide** avant publication aux étudiants ? | ❗ Essentiel | |
| 4.15 | Les étudiants et parents voient-ils les notes **en temps réel** ou seulement après **validation** ? | ❗ Essentiel | |
| 4.16 | Le **suivi de progression** (UE validées, ECTS acquis, semestres terminés) est-il attendu côté étudiant et côté direction ? | Important | |
| 4.17 | L'école peut-elle fournir un **exemplaire de bulletin / relevé de notes** actuel (modèle vierge ou réel anonymisé) ? C'est le moyen le plus fiable de paramétrer les règles de calcul. | ❗ Essentiel | |
