## Votre rôle au quotidien

Le secrétariat est le premier point de contact de l'étudiant. À ce titre, vous :

- accueillez, identifiez et orientez les étudiants ;
- vérifiez la complétude d'un dossier avant de le transmettre au service compétent ;
- traitez les demandes de documents et vérifiez leur statut de paiement ;
- orientez l'étudiant vers le Recouvrement pour tout paiement, reçu ou question de caisse ;
- imprimez les autorisations provisoires et les attestations disponibles ;
- renseignez les étudiants sur l'état de leur demande et les pièces manquantes ;
- signalez les anomalies au service concerné plutôt que de modifier une donnée sensible.

> **Principe de base :** vous ne validez pas à la place d'un autre service. Vous contrôlez, vous renseignez, vous imprimez et vous transmettez.

## Avant de commencer

### Se connecter

1. Utilisez les identifiants remis par l'administration.
2. À la première connexion, changez le mot de passe temporaire depuis **Mon compte**.
3. Si la double authentification est activée, saisissez le code demandé.
4. Ne partagez jamais votre mot de passe et verrouillez votre poste lorsque vous quittez le guichet.

### Vérifier le site actif

Le sélecteur **Site actif** figure en haut du menu. Certains écrans, notamment la **Situation irrégulière**, affichent « Aucun site actif sélectionné » tant qu'aucun site n'est choisi. Sélectionnez le site de votre établissement avant de commencer votre journée.

### Les réflexes du secrétariat

1. **Identifier** l'étudiant : nom, prénom, matricule et, si nécessaire, pièce d'identité.
2. **Vérifier** la demande : type de document, statut et paiement associé.
3. **Contrôler** les pièces : lisibilité, validité et correspondance avec le dossier.
4. **Imprimer** uniquement un document dont le statut permet la remise.
5. **Vérifier** l'état de paiement avant de préparer ou remettre un document.
6. **Orienter** vers le Recouvrement pour encaisser, éditer un reçu ou résoudre une anomalie de caisse.

### Documents et fichiers

- Formats acceptés pour les pièces : **PDF, JPG/JPEG, PNG, HEIC/HEIF**.
- Taille maximale : **20 Mo par fichier**.
- Les documents officiels sont générés par l'application, avec une référence et un QR code de vérification.
- Ne remettez jamais un document dont le nom, le matricule ou le parcours ne correspondent pas à l'étudiant.

## Comprendre les statuts

### Demande d'inscription

| Statut | Signification |
|---|---|
| Soumis | Le dossier a été transmis et attend son contrôle. |
| Authentifié | Les pièces et le bordereau ont été contrôlés. |
| Saisie validée | La saisie comptable a été vérifiée. |
| Transmis au comité | Le dossier attend la décision du comité d'orientation. |
| Validé | L'inscription est validée. |
| Correction demandée | Une correction est attendue de l'étudiant. |
| Rejeté | Le dossier est refusé ; le motif figure dans le détail. |

### Bordereau de paiement

| Statut | Signification |
|---|---|
| En attente | Le bordereau a été déposé et attend son contrôle. |
| Validé | Le bordereau a été authentifié. |
| Rejeté | Le bordereau est refusé ; un nouveau justificatif est nécessaire. |
| En saisie comptable | Le service comptable prépare l'imputation. |
| Traité | Le paiement est imputé et les échéances sont mises à jour. |

Le champ **statut de paiement** peut prendre les valeurs `pending` (en attente), `saisi` (saisi) et `finalise` (finalisé).

### Demande de document

| Statut | Signification |
|---|---|
| Brouillon | La demande est commencée mais non soumise. |
| Soumise | La demande a été transmise. |
| En attente de paiement | Un règlement est nécessaire avant préparation. |
| Payé | Le paiement est enregistré. |
| En préparation | Le document est en cours de préparation. |
| En validation du comité | Le document attend une validation. |
| Validée | La demande est validée. |
| Document prêt | Le document est disponible. |
| Remis | Le document a été remis. |
| Délivrée | Le document a été délivré. |
| Rejetée | La demande est refusée ; le motif est indiqué. |
| Annulée | La demande a été annulée. |

> L'écran peut afficher certains statuts sous leur forme technique, par exemple `en_attente_paiement` pour « En attente de paiement ». Dans ce cas, fiez-vous au libellé du détail.

### Autres statuts

| Élément | Statuts |
|---|---|
| Réclamation | Ouverte, Traitée, Fermée. |
| Clôture de caisse | Ouverte, Clôturée. |
| Échéance | Payée, En retard, Impayée. |
| Dossier étudiant | Actif, Suspendu, Archivé. |
| Réorientation | Soumise, En étude, Approuvée, Rejetée. |
| Demande VAE / VAP | Soumise, En instruction, Acceptée, Rejetée. |

**Où le trouver :** menu **Secretariat > General > Tableau de bord**.

2. Ouvrir le détail d'un bloc pour retrouver les dossiers concernés.
3. Vérifier le graphique de répartition des dossiers et la courbe des documents finalisés.

**Bon à savoir :**

- Le badge **Service actif** indique que le service est ouvert.
- Les compteurs peuvent afficher « Chargement des données… » le temps de la synchronisation.

### 2. Traiter les demandes

![Traiter les demandes](../images-nouveau/secretaire/05_demandes.png)

**Où le trouver :** menu **Secretariat > Documents > Demandes**.

**À quoi sert :** traiter les demandes de documents des étudiants : vérifier la demande, contrôler le paiement et imprimer le document.

**À faire :**

1. Filtrer par **année académique**, **niveau d'étude** et **filière**, ou déplier l'arborescence par dossier.
2. Rechercher un étudiant par nom ou matricule.
3. Filtrer par **statut** pour isoler les demandes à traiter.
4. Cliquer sur **Visualiser** pour contrôler le document et le dossier.
5. Cliquer sur **Imprimer** lorsque le document est prêt et le paiement régularisé.

**Bon à savoir :**

- Le statut `en_attente_paiement` signifie que le document ne doit pas être remis avant règlement.
- La colonne **Source** indique l'origine de la demande (demande volontaire, etc.).
- La colonne **Paiement** affiche « Gratuit » pour les documents sans frais.
- Les cases à cocher permettent de sélectionner plusieurs demandes pour une impression groupée, si l'écran le propose.

### 4. Types de documents

![Types de documents](../images-nouveau/secretaire/07_types-de-documents.png)

**Où le trouver :** menu **Secretariat > Documents > Types de documents**.

**À quoi sert :** configurer les documents proposés aux étudiants et leurs frais.

## Partie 2 — Paiements : relais vers le Recouvrement

> **Périmètre strict :** il n'existe pas de profil « caissier » dans ce circuit. L'encaissement, l'édition du reçu, le journal et la clôture de caisse sont gérés par le Recouvrement (ESA Compta). Le secrétariat vérifie le statut de la demande et oriente l'étudiant ; il ne collecte pas de fonds et ne clôture pas la caisse.

### 5. Orienter une demande payante

**Où le trouver :** dans **Traiter les demandes**, rechercher la demande de document.

**À faire :**

1. Rechercher l'étudiant ou sa demande par nom, matricule ou numéro de demande.
2. Vérifier le type de document, le montant affiché et le statut du paiement.
3. Si le règlement est en attente, indiquer à l'étudiant le service de Recouvrement et les références de sa demande.
4. Reprendre le traitement du document uniquement lorsque le statut requis est enregistré.

**Bon à savoir :**

- Ne collectez pas d'argent au secrétariat et n'utilisez pas le compte d'un collègue.
- Pour un document gratuit, suivez le statut de la demande et les contrôles documentaires habituels.

---

### 6. Reçu de caisse — service compétent

L'édition, la réimpression et la vérification du reçu sont effectuées par le Recouvrement (ESA Compta), qui a enregistré l'encaissement. Pour une demande de justificatif, transmettez au service le numéro de demande ou le matricule de l'étudiant. Le fichier d'exemple [RECU de caisse.html](../../RECU%20de%20caisse.html) est un modèle de démonstration : ses coordonnées, montants et références ne doivent pas être repris comme une transaction réelle.

### 7. Clôture de caisse — service compétent

Le comptage des fonds, la comparaison avec le total théorique et la clôture journalière sont réservés au Recouvrement. Si un étudiant ou un collègue signale un écart, transmettez le numéro du reçu ou de la demande au responsable du Recouvrement ; ne modifiez pas le journal et ne clôturez pas la caisse.

**Où le trouver :** menu **Pedagogique > Admission & Inscription > Demandes**.

- Une seule demande peut être en cours pour une même session.

### 16. Réclamations (vue étudiante)

![Réclamations (vue étudiante)](../images-nouveau/secretaire/22_reclamations.png)

## En cas de problème

| Situation | Que faire |
|---|---|
| Un écran affiche « Aucun site actif sélectionné » | Sélectionnez le site de votre établissement dans le menu, puis rechargez l'écran. |
| Un écran affiche « Accès refusé » | Votre profil ne dispose pas de l'habilitation nécessaire. Contactez l'administrateur ; ne demandez pas les identifiants d'un collègue. |
| Une demande reste « en attente de paiement » | Vérifiez le paiement avant d'imprimer. Orientez l'étudiant vers le service de recouvrement si nécessaire. |
| Un bordereau est rejeté | Lisez le motif dans le détail, puis demandez à l'étudiant de déposer un nouveau justificatif. |
| Un reçu n'apparaît pas ou un écart de caisse est signalé | Orientez vers le Recouvrement ; le secrétariat ne modifie pas le journal et ne clôture pas la caisse. |
| Un document ne s'imprime pas | Vérifiez le statut, le paiement et le lecteur PDF. Réessayez avec un autre navigateur si nécessaire. |
| Une information est erronée dans un dossier | Ne modifiez pas la donnée vous-même : signalez-la au service compétent avec la référence du dossier. |

## Vos documents et votre sécurité

- Les documents officiels comportent une référence et un QR code de vérification. Vérifiez le nom, le matricule et l'année avant remise.
- Ne remettez jamais un document à une personne qui ne peut pas justifier son identité ou son lien avec l'étudiant.
- Ne partagez pas vos identifiants et ne laissez pas votre session ouverte au guichet.
- Déconnectez-vous à la fin de votre service ; la caisse est clôturée par le Recouvrement.
- Signalez immédiatement toute anomalie : document qui ne correspond pas, paiement suspect, accès non autorisé.

## Glossaire

| Terme | Définition |
|---|---|
| Autorisation provisoire | Document généré après l'attribution du matricule définitif, en attente de la carte ou du certificat définitif. |
| Bordereau | Justificatif de paiement déposé par l'étudiant. |
| Clôture de caisse | Réconciliation des encaissements de la journée par le Recouvrement avec le montant réellement présent en caisse. |
| Demande de document | Demande d'attestation, de certificat, de relevé de notes ou d'autre document administratif. |
| Écart de caisse | Différence entre le montant théorique et le montant réel constaté. |
| Matricule | Identifiant unique de l'étudiant dans l'établissement. |
| Quitus | Attestation de paiement délivrée après régularisation. |
| Reçu | Justificatif remis après un encaissement. |
| Session d'inscription | Période pendant laquelle les demandes d'inscription sont ouvertes. |
| Statut technique | Code interne affiché à la place d'un libellé, par exemple `en_attente_paiement`. |
