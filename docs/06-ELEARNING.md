# Pôle E-Learning

## Processus
1. Gestion des cours en ligne (création, modification)
2. Contenu : vidéos, PDFs, supports
3. Quiz (QCM, questions ouvertes)
4. Devoirs à rendre
5. Chat par cours
6. Progression apprenant
7. Certificats de réussite
8. Diffusion en direct (player)

## Pages (15)
Dashboard, Vidéos, PDFs, Quiz, Progression, Certificats, Devoirs, Gestion admin, Détails cours, Player, Chat, Upload support
