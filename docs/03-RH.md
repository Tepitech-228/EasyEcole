### Manquants (gaps critiques)
| Processus | Priorité | Détail |
|-----------|----------|--------|
| **Workflow congés** | 🔴 Haute | Demande → Validation hiérarchique → Solde → Reporting. Pas de modèle `DemandeConges`, ni validation, ni suivi solde. |
| **Recrutement workflow** | 🔴 Haute | Offre → Candidatures → Présélection → Entretien → Décision → Contrat. Actuellement en CRUD pur sans état transition. |
| **Masse salariale prévisionnelle** | 🔴 Haute | Simulation du coût employé avant validation paie. Aucune prévision. |
| **Plan de formation annuel** | 🟡 Moyenne | Budget formation, catalogue, inscriptions, bilan. Actuellement CRUD simple. |
| **Automated contrat alerts** | 🟡 Moyenne | Alerte échéance CDD, fin période d'essai, reconduction. |
| **Budget RH** | 🟡 Moyenne | Enveloppe par département, suivi vs réel. |
| **Compétences / Répertoire** | 🟢 Basse | Matrice des compétences par employé. |
| **Visites médicales** | 🟢 Basse | Suivi des visites médicales obligatoires. |
| **Titres-restaurant / avantages** | 🟢 Basse | Gestion des avantages en nature. |
| **Départs / Retraites** | 🟡 Moyenne | Workflow de départ, solde tout compte, certificat de travail. |
